## 🌟 About This Repository

This repository contains my LeetCode solutions in **Python** and **SQL**.

The goal is not only to provide working answers, but also to explain:

- how to understand the problem;
- how the solution works;
- why the approach is correct;
- the time and space complexity;
- common mistakes and edge cases;
- alternative approaches where relevant;
- the main interview pattern being tested.

The explanations are written in simple language so that beginners can follow the reasoning.
